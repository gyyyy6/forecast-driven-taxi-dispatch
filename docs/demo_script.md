# 3 分钟演示脚本

## 0:00–0:30 项目目标
"NYC 高容量网约车（HVFHV）2023 年 1 月，15 分钟 × 263 个交通小区的需求预测，
并用预测结果驱动一个轻量级调度仿真，回答一个问题：**提前把车放到热点，真的有用吗？**"

## 0:30–1:30 需求热点与预测
- 打开看板「需求热点」tab，拖动时间滑块到 00:30，指出跨年夜峰值：全城 13,624 单/15 分钟；
- 切到「时间趋势」，说明日内双峰与周末差异；
- 一句话交代口径：真实 62.9 万单/天对 200 辆车，服务率天花板只有 1.6%，所以对比实验统一把需求抽稀到 1.25 万单/天。

## 1:30–2:30 Greedy vs Forecast
- 「调度仿真」tab：200 辆车的 Greedy 基线 —— 服务率 82.2%，平均等 6.2 分钟，P90 16.4 分钟；
- 切到 Forecast：82.25%，空驶 +5.5%；
- 亮出比例曲线：0.10 / 0.25 / 0.50 → +0.09 / -0.53 / -0.76pp，空驶 +5.5 / +19.7 / +38.2%；
- 关键一句：**"预调度做对了方向，但这条路太窄。"**

## 2:30–3:00 结论与局限
- 真正的杠杆是匹配半径：30 分钟 → 15 分钟，服务率 +4~11pp、空驶/单减半；
- 机理：预调度与匹配半径互为替代，前者要付空驶，后者零成本；
- 局限：只测了元旦一天、无路况、超时即拒、区域质心距离；预调度的价值需要更长时间尺度的空闲窗口才可能显现。
